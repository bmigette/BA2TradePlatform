### Task 1: Replay contract, codec and immutable store (`ba2_common.core.replay`) — spec step 1

**Files (new):** `packages/common/ba2_common/core/replay/{__init__,schemas,codec,store,context,clock,service}.py`; tests `packages/common/tests/test_replay_codec.py`, `test_replay_store.py`, `test_replay_context_clock.py`, `test_replay_service_export.py`.

**Rules:** the package imports nothing from providers/brokers/DB models and never reads `ba2_common.config` paths; every path is injected. Pure stdlib + pyarrow/pandas (already dependencies) for frames.

**`schemas.py`** — frozen dataclasses with `schema_version = 1`, all times tz-aware UTC or `None` (unknown stays unknown):
- `SessionRecord(session_id, instance_id, started_at, ended_at, exchange_tz, app_version, package_versions: dict, source_revision, dirty, config_hashes: dict, status: "open|finalized|interrupted", capabilities: dict)`.
- `AnalysisRecord(analysis_id (str, host id), attempt_id, session_id, expert_class, expert_instance_id, symbol, use_case: "enter_market|open_positions", scheduled_at, started_at, finished_at, settings_hash, settings_object, bundle_object (hash or None), bundle_capture_status: "captured|unsupported|failed|not_attempted", clock_reads: list[str iso], outcome: "recommendation|skip|error", recommendation_object (hash or None), skip_reason, error, observation_ids: list, branch_flags: dict (e.g. {"as_of_is_none": True}))`.
- `ProviderObservation(observation_id, session_id, analysis_ids: list, provider, method, request_identity: dict (sanitized), invocation_seq, payload_object (hash), payload_kind: "json|frame|scalar|none", response_class: "data|empty|error", content_hash, fetched_at, observed_at, consumed_at, published_at, first_observed_at, provenance: "network|memo_cache|disk_cache|unknown")`.
- `CoverageEntry(session_id, analysis_id, capability: "recorded_expert|gather_tape|historical|decision", status: "match|difference|missing_capture|missing_history|revision_unknown|unsupported|not_run", detail)`.
- `ReplayStatus` string constants for the statuses above.

**`codec.py`** — `encode(obj) -> (kind, bytes, meta)` / `decode(kind, bytes, meta)`; `CODEC_VERSION = 1`. JSON path handles: None, bool, int, float (repr exact; NaN/inf as tagged objects, never dropped), str, list, dict (key order preserved), `Enum` (tagged `{"$enum": "module.Class.NAME"}`), `datetime`/`date` (tagged ISO with tz name/offset; naive stays naive and is tagged), `Decimal` (tagged string), numpy scalars (to Python with a dtype tag). `pandas.DataFrame`/`Series` → tagged reference to a separate Arrow IPC object (index, column order, dtypes, tz preserved; no rounding; row count asserted on round trip). Any other type → raise `UnsupportedCaptureType(type_name, path)`. `freeze(obj)` returns a deep, immutable-by-copy snapshot (DataFrames copied) so later mutation by the expert cannot alter the record. `content_hash(kind, bytes)` = sha256 hex.

**`store.py`** — `ObjectStore(root)`: `put(kind, bytes, meta) -> hash` (write `objects/<hash[:2]>/<hash>.<ext>` via temp file in the same dir + fsync + hash verification + `os.replace`; idempotent when it exists), `get(hash) -> (kind, bytes, meta)`, `exists`, `iter_orphans(grace_seconds)`. `ReplayIndex(root/'index.sqlite')`: WAL, `busy_timeout`, tables `sessions, analyses, observations, observation_links, coverage, objects(hash, kind, size, created_at)`; write API is transactional and commits references only after the objects exist; `list_sessions()`, `analyses(session_id)`, `observations(analysis_id)`; a crash between object publish and index commit leaves an orphan object that is not referenced. Process-safe: two processes writing different sessions concurrently must both succeed (SQLite transactions, no in-process-only lock).

**`context.py`** — `CaptureContext` (per-analysis, held in a `contextvars.ContextVar`; `current()` returns None when capture is off) with `record_observation(...)`, `record_clock_read(dt)`, `set_bundle(bundle)`, `set_outcome(rec|skip|error)`; a `NullContext` sentinel is never used — absence of a context means "off". `capture_scope(store, analysis_meta)` context manager creates the record, yields the context, and on exit hands the finished record to `store.submit(record)` (async queue; see service). Exceptions inside recording are caught at the boundary, counted in `CaptureHealth` (queue_saturation, disk_error, unsupported_type, other) and logged at ERROR **once per analysis**, never re-raised into the expert.

**`clock.py`** — `replay_now(as_of=None) -> datetime`: returns `as_of` when given; else if a `CaptureContext` is active and it is in **replay mode**, returns the next recorded read (raises `ReplayMiss` when exhausted); else reads `datetime.now(timezone.utc)` and, if a capture context is active, records it. This is the injectable evaluation-clock seam of spec §4: production semantics unchanged (wall clock), reads recorded in order.

**`service.py`** — `ReplayStore(root, *, writer: "sync|thread")`: `begin_session(SessionRecord)`, `submit(AnalysisRecord + objects)` (bounded `queue.Queue(maxsize=…)`; on full → `CaptureHealth.queue_saturation += 1`, record dropped with ERROR, coverage `missing_capture`), `finalize_session(session_id)` waits for the queue to drain then marks `finalized`; `mark_interrupted_sessions()` on open; `export_session(session_id, out_dir)` writes `manifest.json` + `coverage.json` + referenced objects (relative refs, content hashes; no absolute paths); `load_bundle(dir) -> SessionBundle` validates schema version and hashes. Module-level seam `set_replay_store(store|None)` / `get_replay_store()` (host-injected; default None = capture off).

**Tests (write first):** codec round trip for every supported type incl. a tz-aware DataFrame with int/float/str/datetime/category columns and a non-unique index; NaN vs None vs 0 distinguished; enum round trip; unsupported type raises with the path; `freeze` isolates from later mutation; store atomicity (simulate crash after object write, before index commit: object present, not referenced, listed by `iter_orphans`); hash mismatch on read raises; two processes (`multiprocessing`) each writing 50 observations into the same root → index consistent, 100 rows; export → load round trip validates hashes and rejects a tampered object; queue saturation increments health and does not raise; `replay_now` records reads in capture mode, replays them in order in replay mode, raises `ReplayMiss` when exhausted, and is a plain wall clock with no context.

**Commit:** `feat(replay): host-neutral replay contract, codec and immutable store (spec step 1)`.
